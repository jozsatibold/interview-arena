# Target Job Description 02: Senior Full-Stack Engineer — Embedded Widgets & Platform

**Company:** NordCart Metrics *(Simulated Nordic E-Commerce SaaS — comparable to Trustpilot / Clerk.io / Sleeknote)*  
**Location:** Remote (EU / Copenhagen HQ)  
**Contract Type:** Full-Time B2B Contractor (`€55 – €65 / hour`)

---

## About the Role
Our widget script runs on **15,000+ online stores** across Europe, rendering personalized product badges and conversion overlays in real time. We need a **Senior Full-Stack Engineer** who obsesses over ultra-small bundle sizes, CDN edge latency, and clean TypeScript full-stack architecture.

## Key Responsibilities
- Architect and maintain ultra-lightweight, framework-agnostic embedded storefront widgets using **Web Components (Lit)** and vanilla TypeScript.
- Optimize **CDN delivery, caching headers, and bundle payloads** (sub-20 KB targets) so merchant Lighthouse scores are never negatively impacted.
- Build and scale internal merchant dashboards and backoffice portals in **Angular / React / Next.js**.
- Develop and maintain high-throughput **Node.js (Express / Fastify / NestJS)** microservices backed by **PostgreSQL / MongoDB**.
- Implement feature flags (**ConfigCat** or similar), real-time error monitoring (**TrackJS / Sentry**), and end-to-end **Playwright** test suites across diverse browser environments.

## Required Qualifications
- **6+ years** full-stack JavaScript/TypeScript experience in high-traffic SaaS or e-commerce environments.
- Hands-on experience optimizing embedded third-party JavaScript widgets or micro-frontends (DOM isolation, Shadow DOM, bundle splitting, CDN tuning).
- Strong backend experience in **Node.js** (`Express`, `Fastify`, or `NestJS`) and relational/NoSQL databases.
- Strong debugging instincts for cross-browser, third-party-site edge cases and production observability.
- Comfortable working autonomously in a flat Scandinavian engineering culture.

## Nice to Have
- Experience with **AI/LLM workflow integration** or experimentation with local/cloud LLMs for developer tooling and product features.
- Experience with **GCP / AWS** cloud infrastructure and CI/CD pipelines.
